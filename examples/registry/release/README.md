## Contents

1. [Purpose](#purpose)

## Purpose

This directory is reserved for reviewed, distributable registry outputs. It is intentionally
empty until generated OSCAL artifacts and release receipts have passed conformance review.

## Rules

- Release files are outputs, never editable registry source.
- A release must identify the source Git revision, generator version, and validation results.
- Do not publish provisional or unreviewed framework mappings as authoritative compliance claims.
